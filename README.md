## 🎮 教學關卡設計（鷹架理論 Scaffolding）

本教材依據國中生認知負荷理論，將經典「Toads and Frogs Puzzle」設計為四階階梯難度，兼顧落後學生保底與高成就學生延伸：

| 關卡 | 編制 | 荷葉數 | 最少步數公式 ($N^2+2N$) | 演算法教學重點 |
| :--- | :--- | :--- | :--- | :--- |
| **🌱 Level 1** | **1 vs 1** | 3 片 | **3 步** | **建立信心**：理解「滑步」與「跨跳」基本規則（5 秒通關保底）。 |
| **🌿 Level 2** | **2 vs 2** | 5 片 | **8 步** | **模式識別**：體驗「同色不牽手」與「能跳就跳」兩大核心心法。 |
| **👑 Level 3** | **3 vs 3** | 7 片 | **15 步** | **規律遷移**：完整驗證波浪遞增遞減的 1-2-3-3-3-2-1 最優調度路徑。 |
| **🔥 Level 4** | **4 vs 4** | 9 片 | **24 步** | **極限挑戰**：高成就學生的演算法燒腦大挑戰。 |

## ⚙️ 核心技術特點 (Vanilla Web Engineering)

1. **零依賴原生架構**：純 HTML5 + CSS3 + Vanilla JavaScript，單一靜態網頁，無需伺服器或資料庫。
2. **人因工程適配**：
   * 所有按鍵與角色觸控熱區均 $\ge 46\text{px}$，針對智慧黑板手指點擊與學生 iPad 防誤觸最佳化。
   * 防雙擊縮放（`touch-action: manipulation;`）。
3. **Web Audio API 原生音效合成**：
   * 起跳彈簧音（Sine Ramp）、落水水花音（Triangle）、死棋鋸齒音（Sawtooth）與通關和弦完全由瀏覽器即時合成，零音檔載入延遲。
4. **雙層 SVG 動畫隔離架構**：
   * 外層 `<g class="frog-group">` 以原生 SVG `transform` 屬性鎖定世界座標。
   * 內層 `<g class="frog-anim">` 承載局部 Squash & Stretch 物理形變與呼吸動畫，徹底杜絕 Keyframe 覆寫瞬移渲染瑕疵。
5. **即時 BFS 最優路徑求解器**：
   * 切換任何關卡均能在 5ms 內以廣度優先搜尋推導最優解，支援「白話演算法自動演示播放器」與步驟高亮跟隨。
6. **通關成果截圖**：
   * 整合 `html2canvas`，學生破關可一鍵產生帶有步數、秒數與三星評等的過關證書。
